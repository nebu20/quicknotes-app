
# QuickNotes

QuickNotes is a simple, responsive note-taking web application for creating, organizing, searching, and deleting notes.

## Features

- Add notes with text and a category.
- Organize notes into Personal, Work, and Study.
- Validate empty notes and enforce a 200-character limit.
- Display the creation date and time.
- Delete individual notes.
- Clear all notes after confirmation.
- Display the total number of notes.
- Search notes without case sensitivity.
- Save notes in browser localStorage.
- Responsive layout for desktop and mobile devices.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Alternatively, use the Live Server extension in Visual Studio Code.
